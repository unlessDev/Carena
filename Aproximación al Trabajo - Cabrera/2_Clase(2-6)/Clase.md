# **Software Libre**

Todo programa que se distribuye bajo una licencia que respete 4 libertades fundamentales para todos los usuarios.

**Las 4 Caracteristicas Son: (En realidad son 5 pero va del 0 al 4)**
--
- 
- Usar: 
- Redistribuir: 
- Estudiar: 
- Modificar: 

# Linea de tiempo
1983 --> Richard M Satlmand = Armó un sistema operativo que llamó GNU que implicaba que el software sea libremente modificado.

1985 --> Apareció el manifiesto del software libre.
1985 --> Se creó la asociación free software foundation

1990 --> Marc Anderssen y Eric Bina crean NETSCAPE COMUNICATION SUIT =  crea las bases de navegador web y correo electrónico.
